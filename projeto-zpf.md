# 🔥 Projeto de Firewall ZPF

## 1. Objetivo

Estudar e documentar o funcionamento de um firewall baseado em zonas (Zone-Based Policy Firewall), utilizando o Cisco Packet Tracer.

O objetivo é compreender como as políticas de segurança controlam o tráfego entre diferentes zonas de uma rede.

## 2. Tecnologias utilizadas

- Cisco Packet Tracer
- Conceitos de segurança de redes
- Firewall baseado em zonas (ZPF)

## 3. Conceitos estudados

- Zonas de segurança
- Classificação do tráfego de rede
- Políticas de segurança entre zonas
- Controle de tráfego
- Permissão e bloqueio de comunicações

## 4. Funcionamento do ZPF

O Zone-Based Policy Firewall organiza interfaces de rede em zonas de segurança.

As políticas aplicadas entre essas zonas determinam como o tráfego será tratado.

Dependendo da política configurada, uma comunicação poderá ser permitida, inspecionada ou bloqueada.

## 5. Etapas do laboratório

- Estudo da organização das zonas de segurança.
- Análise das políticas de tráfego entre zonas.
- Estudo das regras de controle de comunicação.
- Documentação dos conceitos aplicados ao laboratório.

## 6. Resultados e aprendizados

Este projeto contribui para o desenvolvimento de conhecimentos em:

- Segurança de redes de computadores.
- Controle de tráfego entre zonas.
- Políticas de firewall.
- Fundamentos de proteção de redes.

## 7. Conclusão

O estudo do ZPF permite compreender como políticas de segurança podem ser utilizadas para controlar a comunicação entre diferentes segmentos de uma rede.
