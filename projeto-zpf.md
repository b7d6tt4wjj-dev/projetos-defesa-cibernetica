# Projeto de Firewall ZPF
Documentar a configuração de um firewall baseado em zonas (ZPF) no Cisco Packet Tracer, aplicando políticas de segurança para controlar o tráfego entre redes.

## Objetivo
Documentar a configuração de um firewall baseado em zonas (ZPF) no Cisco Packet Tracer.

## Configuração realizada
- Criação de zonas de segurança no firewall.
- Definição de políticas para controlar o tráfego entre as zonas.
- Aplicação de regras para permitir ou bloquear comunicações entre redes.

 ## Resultado
- O laboratório permitiu praticar conceitos de segurança de redes, filtragem de tráfego e controle de acesso utilizando um firewall baseado em zonas.

 ## Conclusão
 Este projeto contribuiu para o desenvolvimento de conhecimentos práticos em firewall, políticas de segurança e proteção de redes de computadores.
